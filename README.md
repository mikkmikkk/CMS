# Counseling Monitoring System (CMS)

Counseling Monitoring System (CMS) is designed to simplify and enhance the university’s counseling services by automating manual processes and providing a user-friendly interface. The primary purpose of the guidance office is to guide student assistance and monitor the counseling process across the university


## Tech Stack

**Frontend:** React, TailwindCSS

**Backend:** FastAPI 


## Installation

```bash
  cd cms
  npm install 
  npm run dev
```
